## 📖 What is a Variable?

A variable is a **container for storing data**. Think of it like a labeled box where you put things.

```javascript
let age = 25;
```

Here:
- `let` = keyword that creates the variable
- `age` = the name (label) of the box
- `=` = assignment operator (puts something in the box)
- `25` = the value stored inside

## 🔑 var vs let vs const

JavaScript has three ways to declare variables. Understanding the difference is crucial.

### var (Old Way - Avoid This)

```javascript
var name = "John";
var name = "Jane";  // No error! Can redeclare
name = "Bob";       // Can reassign

// Problem: var is function-scoped, not block-scoped
if (true) {
  var x = 10;
}
console.log(x);  // 10 - x leaked out of the if block!
```

**Why avoid var?** It can cause unexpected bugs because of its scoping rules.

### let (Modern - Use for Changing Values)

```javascript
let count = 0;
count = 1;        // ✅ Can reassign
let count = 2;    // ❌ Error! Cannot redeclare

// let is block-scoped
if (true) {
  let y = 10;
}
console.log(y);   // ❌ Error! y is not defined
```

**Use let when:** The value will change later.

### const (Modern - Use by Default)

```javascript
const PI = 3.14159;
PI = 3;           // ❌ Error! Cannot reassign

const user = { name: "John" };
user.name = "Jane";  // ✅ This works! (we'll explain why)
user = {};           // ❌ Error! Cannot reassign the variable itself
```

**Use const when:** The value won't be reassigned (most of the time).

### 📝 Rule of Thumb
1. Use `const` by default
2. Use `let` only when you need to reassign
3. Never use `var`

## 📊 Data Types

JavaScript has **8 data types**. Let's master each one.

### 1. String (Text)

```javascript
const firstName = "John";           // Double quotes
const lastName = 'Doe';             // Single quotes
const greeting = `Hello, ${firstName}!`;  // Template literal (backticks)

// String properties and methods
console.log(firstName.length);      // 4
console.log(firstName.toUpperCase()); // "JOHN"
console.log(firstName.toLowerCase()); // "john"
console.log(firstName[0]);          // "J" (first character)
console.log(firstName.includes("oh")); // true
console.log(firstName.indexOf("o")); // 1 (position of "o")
console.log(firstName.slice(0, 2)); // "Jo" (characters 0-1)
```

**Template Literals** are powerful:
```javascript
const name = "John";
const age = 25;

// Old way (concatenation)
const message1 = "My name is " + name + " and I am " + age + " years old.";

// New way (template literal) - much cleaner!
const message2 = `My name is ${name} and I am ${age} years old.`;

// Multi-line strings
const html = `
  <div>
    <h1>Hello</h1>
    <p>Welcome!</p>
  </div>
`;
```

### 2. Number

```javascript
const integer = 42;
const decimal = 3.14;
const negative = -10;

// Special numbers
const infinity = Infinity;
const notANumber = NaN;  // Result of invalid math operations

// Number methods
console.log(Math.round(3.7));   // 4
console.log(Math.floor(3.7));   // 3 (round down)
console.log(Math.ceil(3.2));    // 4 (round up)
console.log(Math.random());     // Random 0-1
console.log(Math.max(1, 5, 3)); // 5
console.log(Math.min(1, 5, 3)); // 1

// Convert string to number
const str = "42";
const num1 = Number(str);       // 42
const num2 = parseInt(str);     // 42 (integer)
const num3 = parseFloat("3.14"); // 3.14

// Check if valid number
console.log(isNaN("hello"));    // true
console.log(isNaN(42));         // false
```

### 3. Boolean (true/false)

```javascript
const isLoggedIn = true;
const hasPermission = false;

// Truthy and Falsy values
// Falsy: false, 0, "", null, undefined, NaN
// Truthy: everything else

if ("hello") {
  console.log("This runs because non-empty string is truthy");
}

if (0) {
  console.log("This won't run because 0 is falsy");
}

// Convert to boolean
console.log(Boolean("hello"));  // true
console.log(Boolean(""));       // false
console.log(Boolean(1));        // true
console.log(Boolean(0));        // false

// Double NOT trick (shorthand for Boolean())
console.log(!!"hello");         // true
console.log(!!0);               // false
```

### 4. null (Intentional Empty)

```javascript
let selectedUser = null;  // Explicitly set to "nothing"

// null means "I intentionally set this to empty"
if (selectedUser === null) {
  console.log("No user selected");
}
```

### 5. undefined (Not Yet Assigned)

```javascript
let name;
console.log(name);  // undefined

// undefined means "this exists but has no value yet"
// or "this property doesn't exist"

const user = { name: "John" };
console.log(user.age);  // undefined (property doesn't exist)
```

### 6. Symbol (Unique Identifier)

```javascript
// Symbols are unique, even with same description
const id1 = Symbol("id");
const id2 = Symbol("id");
console.log(id1 === id2);  // false

// Used for unique object keys (advanced topic)
```

### 7. BigInt (Very Large Numbers)

```javascript
const bigNumber = 9007199254740991n;  // Note the 'n' suffix
const anotherBig = BigInt("9007199254740991");

// Used when you need numbers larger than Number.MAX_SAFE_INTEGER
```

### 8. Object (Complex Data)

```javascript
// Objects store key-value pairs
const user = {
  name: "John",
  age: 25,
  isAdmin: false
};

// Access properties
console.log(user.name);       // "John" (dot notation)
console.log(user["age"]);     // 25 (bracket notation)

// Modify properties
user.age = 26;
user.email = "john@example.com";  // Add new property

// Arrays are also objects
const numbers = [1, 2, 3, 4, 5];
console.log(numbers[0]);      // 1
console.log(numbers.length);  // 5
```

## 🔧 Operators

### Arithmetic Operators

```javascript
const a = 10;
const b = 3;

console.log(a + b);   // 13 (addition)
console.log(a - b);   // 7 (subtraction)
console.log(a * b);   // 30 (multiplication)
console.log(a / b);   // 3.333... (division)
console.log(a % b);   // 1 (modulo - remainder)
console.log(a ** b);  // 1000 (exponentiation - 10^3)

// Increment/Decrement
let count = 5;
count++;              // count is now 6
count--;              // count is now 5
count += 3;           // count is now 8 (same as count = count + 3)
count -= 2;           // count is now 6
count *= 2;           // count is now 12
count /= 3;           // count is now 4
```

### Comparison Operators

```javascript
const x = 5;
const y = "5";

// Loose equality (converts types) - AVOID
console.log(x == y);   // true (5 == "5")
console.log(x != y);   // false

// Strict equality (no type conversion) - USE THIS
console.log(x === y);  // false (number !== string)
console.log(x !== y);  // true

// Other comparisons
console.log(5 > 3);    // true
console.log(5 < 3);    // false
console.log(5 >= 5);   // true
console.log(5 <= 4);   // false
```

**Always use `===` and `!==`** to avoid type coercion bugs.

### Logical Operators

```javascript
const a = true;
const b = false;

// AND - both must be true
console.log(a && b);   // false
console.log(a && a);   // true

// OR - at least one must be true
console.log(a || b);   // true
console.log(b || b);   // false

// NOT - inverts the value
console.log(!a);       // false
console.log(!b);       // true

// Practical example
const isLoggedIn = true;
const isAdmin = false;

if (isLoggedIn && isAdmin) {
  console.log("Show admin panel");
}

if (isLoggedIn || isAdmin) {
  console.log("Show something");  // This runs
}
```

### Short-Circuit Evaluation

```javascript
// AND returns first falsy value, or last value if all truthy
console.log("hello" && "world");  // "world"
console.log(0 && "world");        // 0
console.log("" && "world");       // ""

// OR returns first truthy value, or last value if all falsy
console.log("hello" || "world");  // "hello"
console.log(0 || "default");      // "default"
console.log("" || null || "fallback");  // "fallback"

// Practical use: default values
const username = inputName || "Guest";

// Nullish coalescing (only null/undefined trigger fallback)
const count = 0;
console.log(count || 10);   // 10 (0 is falsy)
console.log(count ?? 10);   // 0 (0 is not null/undefined)
```

### Ternary Operator

```javascript
// condition ? valueIfTrue : valueIfFalse
const age = 20;
const status = age >= 18 ? "Adult" : "Minor";
console.log(status);  // "Adult"

// Same as:
let status2;
if (age >= 18) {
  status2 = "Adult";
} else {
  status2 = "Minor";
}
```

## ⚠️ Type Coercion (Watch Out!)

JavaScript automatically converts types, which can cause bugs.

```javascript
// String + Number = String
console.log("5" + 3);      // "53" (number becomes string)
console.log("5" - 3);      // 2 (string becomes number)

// Comparisons
console.log("10" > 9);     // true (string becomes number)
console.log("10" > "9");   // false (string comparison: "1" < "9")

// Boolean conversions
console.log(1 + true);     // 2 (true becomes 1)
console.log(1 + false);    // 1 (false becomes 0)

// Weird stuff
console.log([] + []);      // "" (empty string)
console.log([] + {});      // "[object Object]"
console.log({} + []);      // 0 or "[object Object]" depending on context
```

**How to avoid bugs:**
1. Always use `===` instead of `==`
2. Explicitly convert types when needed
3. Be careful with `+` operator (use `Number()` if you want math)

## 🔍 Checking Types

```javascript
console.log(typeof "hello");     // "string"
console.log(typeof 42);          // "number"
console.log(typeof true);        // "boolean"
console.log(typeof undefined);   // "undefined"
console.log(typeof null);        // "object" (this is a JS bug!)
console.log(typeof {});          // "object"
console.log(typeof []);          // "object" (arrays are objects)
console.log(typeof function(){}); // "function"

// Better way to check arrays
console.log(Array.isArray([]));  // true
console.log(Array.isArray({}));  // false

// Check for null specifically
const value = null;
console.log(value === null);     // true
```
