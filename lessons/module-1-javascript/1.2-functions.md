## 📖 What is a Function?

A function is a **reusable block of code** that performs a specific task.

Think of it like a recipe:
- **Input (ingredients):** Parameters you pass in
- **Process (instructions):** Code inside the function
- **Output (dish):** The return value

```javascript
// Define the function (write the recipe)
function greet(name) {
  return `Hello, ${name}!`;
}

// Call the function (follow the recipe)
const message = greet("John");
console.log(message);  // "Hello, John!"
```

## 🔧 Ways to Declare Functions

### 1. Function Declaration

```javascript
function add(a, b) {
  return a + b;
}

console.log(add(2, 3));  // 5
```

**Characteristics:**
- Hoisted (can be called before declaration)
- Has a name
- Most traditional way

```javascript
// This works because of hoisting
sayHello();  // "Hello!"

function sayHello() {
  console.log("Hello!");
}
```

### 2. Function Expression

```javascript
const add = function(a, b) {
  return a + b;
};

console.log(add(2, 3));  // 5
```

**Characteristics:**
- NOT hoisted (must be defined before use)
- Can be anonymous (no name)
- Stored in a variable

```javascript
// This does NOT work
// sayHello();  // Error: Cannot access before initialization

const sayHello = function() {
  console.log("Hello!");
};

sayHello();  // "Hello!"
```

### 3. Arrow Function (ES6+)

```javascript
// Full syntax
const add = (a, b) => {
  return a + b;
};

// Short syntax (implicit return)
const addShort = (a, b) => a + b;

// Single parameter (no parentheses needed)
const double = x => x * 2;

// No parameters
const sayHi = () => "Hi!";

console.log(add(2, 3));       // 5
console.log(addShort(2, 3));  // 5
console.log(double(5));       // 10
console.log(sayHi());         // "Hi!"
```

**When to use arrow functions:**
- Short, simple functions
- Callbacks (we'll cover this soon)
- When you need to preserve `this` context (advanced topic)

### 4. Immediately Invoked Function Expression (IIFE)

```javascript
// Runs immediately when defined
(function() {
  console.log("I run immediately!");
})();

// With arrow function
(() => {
  console.log("Me too!");
})();

// Useful for creating private scope
const counter = (() => {
  let count = 0;  // Private variable
  return {
    increment: () => ++count,
    getCount: () => count
  };
})();

console.log(counter.increment());  // 1
console.log(counter.increment());  // 2
console.log(counter.getCount());   // 2
```

## 📥 Parameters and Arguments

### Basic Parameters

```javascript
function greet(firstName, lastName) {
  return `Hello, ${firstName} ${lastName}!`;
}

// Arguments are the actual values passed
greet("John", "Doe");  // "Hello, John Doe!"
```

### Default Parameters

```javascript
function greet(name = "Guest") {
  return `Hello, ${name}!`;
}

greet("John");  // "Hello, John!"
greet();        // "Hello, Guest!"
```

### Rest Parameters (...)

```javascript
// Collect remaining arguments into an array
function sum(...numbers) {
  return numbers.reduce((total, num) => total + num, 0);
}

console.log(sum(1, 2, 3));        // 6
console.log(sum(1, 2, 3, 4, 5));  // 15

// Can combine with regular parameters
function introduce(greeting, ...names) {
  return `${greeting}, ${names.join(" and ")}!`;
}

console.log(introduce("Hello", "John", "Jane", "Bob"));
// "Hello, John and Jane and Bob!"
```

### Destructuring Parameters

```javascript
// Object destructuring
function createUser({ name, age, email }) {
  return { name, age, email, createdAt: new Date() };
}

createUser({ name: "John", age: 25, email: "john@example.com" });

// With defaults
function greetUser({ name = "Guest", greeting = "Hello" } = {}) {
  return `${greeting}, ${name}!`;
}

greetUser({ name: "John" });  // "Hello, John!"
greetUser();                   // "Hello, Guest!"

// Array destructuring
function getFirstTwo([first, second]) {
  return { first, second };
}

getFirstTwo([1, 2, 3, 4]);  // { first: 1, second: 2 }
```

## 📤 Return Values

### Single Return

```javascript
function add(a, b) {
  return a + b;
  console.log("This never runs");  // Code after return is unreachable
}
```

### Multiple Returns (Early Exit)

```javascript
function checkAge(age) {
  if (age < 0) {
    return "Invalid age";
  }
  
  if (age < 18) {
    return "Minor";
  }
  
  return "Adult";
}

console.log(checkAge(-5));  // "Invalid age"
console.log(checkAge(15));  // "Minor"
console.log(checkAge(25));  // "Adult"
```

### Returning Objects

```javascript
// Need parentheses for implicit return of object
const createUser = (name, age) => ({ name, age });

// Same as:
const createUser2 = (name, age) => {
  return { name, age };
};

console.log(createUser("John", 25));  // { name: "John", age: 25 }
```

### Returning Functions

```javascript
function multiplier(factor) {
  return function(number) {
    return number * factor;
  };
}

const double = multiplier(2);
const triple = multiplier(3);

console.log(double(5));  // 10
console.log(triple(5));  // 15

// Arrow function version
const multiplierArrow = factor => number => number * factor;
```

### No Return (undefined)

```javascript
function logMessage(message) {
  console.log(message);
  // No return statement
}

const result = logMessage("Hello");
console.log(result);  // undefined
```

## 🔄 Callback Functions

A callback is a function passed as an argument to another function.

### Basic Callback

```javascript
function processUser(name, callback) {
  const user = { name, id: Math.random() };
  callback(user);  // Call the function that was passed in
}

// Pass a function as argument
processUser("John", function(user) {
  console.log("User created:", user);
});

// Arrow function version
processUser("Jane", user => console.log("User created:", user));
```

### Array Methods with Callbacks

```javascript
const numbers = [1, 2, 3, 4, 5];

// forEach - do something with each element
numbers.forEach(num => console.log(num));

// map - transform each element
const doubled = numbers.map(num => num * 2);
console.log(doubled);  // [2, 4, 6, 8, 10]

// filter - keep elements that pass a test
const evens = numbers.filter(num => num % 2 === 0);
console.log(evens);  // [2, 4]

// find - get first element that passes test
const firstEven = numbers.find(num => num % 2 === 0);
console.log(firstEven);  // 2

// reduce - combine all elements into one value
const sum = numbers.reduce((total, num) => total + num, 0);
console.log(sum);  // 15

// some - check if ANY element passes test
const hasEven = numbers.some(num => num % 2 === 0);
console.log(hasEven);  // true

// every - check if ALL elements pass test
const allPositive = numbers.every(num => num > 0);
console.log(allPositive);  // true
```

### Chaining Methods

```javascript
const users = [
  { name: "John", age: 25, active: true },
  { name: "Jane", age: 17, active: true },
  { name: "Bob", age: 30, active: false },
  { name: "Alice", age: 22, active: true }
];

// Get names of active adult users
const activeAdultNames = users
  .filter(user => user.active)           // Keep active users
  .filter(user => user.age >= 18)        // Keep adults
  .map(user => user.name)                // Get just names
  .sort();                               // Sort alphabetically

console.log(activeAdultNames);  // ["Alice", "John"]
```

## ✨ Pure Functions

A pure function:
1. Always returns the same output for the same input
2. Has no side effects (doesn't modify external state)

### Pure Function Example

```javascript
// PURE - same input always gives same output
function add(a, b) {
  return a + b;
}

add(2, 3);  // Always 5
add(2, 3);  // Always 5

// PURE - doesn't modify the original array
function addItem(array, item) {
  return [...array, item];  // Returns new array
}

const original = [1, 2, 3];
const newArray = addItem(original, 4);
console.log(original);   // [1, 2, 3] - unchanged
console.log(newArray);   // [1, 2, 3, 4]
```

### Impure Function Example

```javascript
// IMPURE - depends on external state
let counter = 0;
function increment() {
  counter++;  // Modifies external variable
  return counter;
}

increment();  // 1
increment();  // 2 - different result!

// IMPURE - modifies the input
function addItemBad(array, item) {
  array.push(item);  // Modifies original array
  return array;
}

const original = [1, 2, 3];
addItemBad(original, 4);
console.log(original);  // [1, 2, 3, 4] - modified!
```

### Why Pure Functions Matter

1. **Predictable:** Easy to test and debug
2. **Reusable:** No hidden dependencies
3. **Cacheable:** Same input = same output, can cache results

## 🎯 Function Best Practices

### 1. Single Responsibility

```javascript
// BAD - does too many things
function processUser(userData) {
  // Validate
  if (!userData.email) throw new Error("Email required");
  // Format
  userData.email = userData.email.toLowerCase();
  // Save to database
  database.save(userData);
  // Send email
  emailService.send(userData.email, "Welcome!");
}

// GOOD - each function does one thing
function validateUser(userData) {
  if (!userData.email) throw new Error("Email required");
  return true;
}

function formatUser(userData) {
  return {
    ...userData,
    email: userData.email.toLowerCase()
  };
}

function saveUser(userData) {
  return database.save(userData);
}

function sendWelcomeEmail(email) {
  return emailService.send(email, "Welcome!");
}
```

### 2. Descriptive Names

```javascript
// BAD
function proc(d) { ... }
function handle(x) { ... }

// GOOD
function processPayment(paymentData) { ... }
function handleUserLogin(credentials) { ... }
function calculateTotalPrice(items) { ... }
function isValidEmail(email) { ... }  // Boolean functions start with is/has/can
```

### 3. Keep Functions Small

```javascript
// If a function is more than 20-30 lines, consider breaking it up
// Each function should be readable at a glance
```

### 4. Avoid Side Effects When Possible

```javascript
// BAD - modifies external state
let total = 0;
function addToTotal(amount) {
  total += amount;
}

// GOOD - returns new value
function addToTotal(currentTotal, amount) {
  return currentTotal + amount;
}
```

## 🎯 Summary

- Functions are reusable blocks of code
- Three main ways to declare: declaration, expression, arrow
- Arrow functions are concise but have different `this` behavior
- Callbacks are functions passed to other functions
- Array methods (map, filter, reduce) are powerful with callbacks
- Pure functions are predictable and easier to test
- Keep functions small and focused on one task
