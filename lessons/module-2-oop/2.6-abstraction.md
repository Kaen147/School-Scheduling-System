## 📖 What is Abstraction?

Abstraction means hiding complex implementation details and showing only the necessary features. It's about creating a simple interface for complex operations.

### Real-World Example

When you drive a car:
- **What you see:** Steering wheel, pedals, gear shift
- **What's hidden:** Engine mechanics, fuel injection, transmission

You don't need to understand how the engine works to drive the car.

### Code Example

```javascript
// Complex implementation hidden
class EmailService {
  // Simple public interface
  send(to, subject, body) {
    this.#validateEmail(to);
    this.#connect();
    this.#authenticate();
    this.#formatMessage(subject, body);
    this.#transmit(to);
    this.#disconnect();
    this.#logSuccess(to);
  }
  
  // All complexity hidden in private methods
  #validateEmail(email) {
    const regex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
    if (!regex.test(email)) {
      throw new Error("Invalid email address");
    }
  }
  
  #connect() {
    console.log("Connecting to SMTP server...");
    // Complex connection logic
  }
  
  #authenticate() {
    console.log("Authenticating...");
    // OAuth, API keys, etc.
  }
  
  #formatMessage(subject, body) {
    // MIME encoding, headers, etc.
  }
  
  #transmit(to) {
    console.log(`Transmitting to ${to}...`);
    // Network protocols, retries, etc.
  }
  
  #disconnect() {
    console.log("Disconnecting...");
  }
  
  #logSuccess(to) {
    console.log(`Email sent to ${to}`);
  }
}

// User only needs to know this:
const email = new EmailService();
email.send("user@example.com", "Hello", "How are you?");
```

## 🏗️ Abstract Classes

Abstract classes define a template that subclasses must follow:

```javascript
class Database {
  constructor() {
    if (new.target === Database) {
      throw new Error("Database is abstract and cannot be instantiated");
    }
  }
  
  // Abstract methods - must be implemented by subclasses
  connect() {
    throw new Error("Subclass must implement connect()");
  }
  
  disconnect() {
    throw new Error("Subclass must implement disconnect()");
  }
  
  query(sql) {
    throw new Error("Subclass must implement query()");
  }
  
  // Concrete method - shared implementation
  async executeWithRetry(sql, maxRetries = 3) {
    for (let i = 0; i < maxRetries; i++) {
      try {
        return await this.query(sql);
      } catch (error) {
        if (i === maxRetries - 1) throw error;
        console.log(`Retry ${i + 1}/${maxRetries}`);
      }
    }
  }
}

class MySQLDatabase extends Database {
  connect() {
    console.log("Connecting to MySQL...");
    // MySQL-specific connection
  }
  
  disconnect() {
    console.log("Disconnecting from MySQL...");
  }
  
  query(sql) {
    console.log(`MySQL executing: ${sql}`);
    // MySQL-specific query execution
    return { rows: [] };
  }
}

class PostgreSQLDatabase extends Database {
  connect() {
    console.log("Connecting to PostgreSQL...");
    // PostgreSQL-specific connection
  }
  
  disconnect() {
    console.log("Disconnecting from PostgreSQL...");
  }
  
  query(sql) {
    console.log(`PostgreSQL executing: ${sql}`);
    // PostgreSQL-specific query execution
    return { rows: [] };
  }
}

// Can't instantiate abstract class
// const db = new Database();  // Error!

// Must use concrete implementations
const mysql = new MySQLDatabase();
mysql.connect();
mysql.query("SELECT * FROM users");
```

## 🎨 Levels of Abstraction

### Low-Level (Detailed)

```javascript
// Low-level: Working with raw data
const buffer = new ArrayBuffer(16);
const view = new DataView(buffer);
view.setInt32(0, 42);
view.setFloat64(4, 3.14159);
```

### Mid-Level

```javascript
// Mid-level: Working with structured data
const data = {
  id: 42,
  value: 3.14159
};
localStorage.setItem("data", JSON.stringify(data));
```

### High-Level (Abstract)

```javascript
// High-level: Working with domain concepts
class UserPreferences {
  #storage;
  
  constructor(storage = localStorage) {
    this.#storage = storage;
  }
  
  save(preferences) {
    this.#storage.setItem("preferences", JSON.stringify(preferences));
  }
  
  load() {
    const data = this.#storage.getItem("preferences");
    return data ? JSON.parse(data) : {};
  }
}

const prefs = new UserPreferences();
prefs.save({ theme: "dark", language: "en" });
```

## 🔧 Abstraction Patterns

### Facade Pattern

Provide a simple interface to a complex subsystem:

```javascript
// Complex subsystems
class CPU {
  freeze() { console.log("CPU frozen"); }
  jump(address) { console.log(`CPU jumping to ${address}`); }
  execute() { console.log("CPU executing"); }
}

class Memory {
  load(address, data) { 
    console.log(`Memory loading ${data} at ${address}`); 
  }
}

class HardDrive {
  read(sector, size) { 
    console.log(`HardDrive reading ${size} bytes from sector ${sector}`);
    return "boot data";
  }
}

// Facade - simple interface
class Computer {
  #cpu;
  #memory;
  #hardDrive;
  
  constructor() {
    this.#cpu = new CPU();
    this.#memory = new Memory();
    this.#hardDrive = new HardDrive();
  }
  
  // Simple method hides complex boot sequence
  start() {
    this.#cpu.freeze();
    this.#memory.load(0, this.#hardDrive.read(0, 1024));
    this.#cpu.jump(0);
    this.#cpu.execute();
    console.log("Computer started!");
  }
}

// User just calls start()
const computer = new Computer();
computer.start();
```

### Repository Pattern

Abstract data access:

```javascript
// Abstract repository
class Repository {
  findAll() { throw new Error("Not implemented"); }
  findById(id) { throw new Error("Not implemented"); }
  create(entity) { throw new Error("Not implemented"); }
  update(id, entity) { throw new Error("Not implemented"); }
  delete(id) { throw new Error("Not implemented"); }
}

// Concrete implementation - could be API, database, etc.
class UserRepository extends Repository {
  #apiUrl = "/api/users";
  
  async findAll() {
    const response = await fetch(this.#apiUrl);
    return response.json();
  }
  
  async findById(id) {
    const response = await fetch(`${this.#apiUrl}/${id}`);
    return response.json();
  }
  
  async create(user) {
    const response = await fetch(this.#apiUrl, {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify(user)
    });
    return response.json();
  }
  
  async update(id, user) {
    const response = await fetch(`${this.#apiUrl}/${id}`, {
      method: "PUT",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify(user)
    });
    return response.json();
  }
  
  async delete(id) {
    await fetch(`${this.#apiUrl}/${id}`, { method: "DELETE" });
  }
}

// Usage - doesn't know about HTTP, APIs, etc.
class UserService {
  constructor(repository) {
    this.repository = repository;
  }
  
  async getAllUsers() {
    return this.repository.findAll();
  }
  
  async getUser(id) {
    return this.repository.findById(id);
  }
}
```

### Service Layer

Abstract business logic:

```javascript
class OrderService {
  #orderRepository;
  #inventoryService;
  #paymentService;
  #notificationService;
  
  constructor(orderRepo, inventoryService, paymentService, notificationService) {
    this.#orderRepository = orderRepo;
    this.#inventoryService = inventoryService;
    this.#paymentService = paymentService;
    this.#notificationService = notificationService;
  }
  
  // Simple interface hides complex orchestration
  async placeOrder(userId, items, paymentInfo) {
    // Check inventory
    for (const item of items) {
      const available = await this.#inventoryService.checkAvailability(item.productId, item.quantity);
      if (!available) {
        throw new Error(`${item.productId} is out of stock`);
      }
    }
    
    // Calculate total
    const total = items.reduce((sum, item) => sum + item.price * item.quantity, 0);
    
    // Process payment
    const payment = await this.#paymentService.charge(paymentInfo, total);
    if (!payment.success) {
      throw new Error("Payment failed");
    }
    
    // Create order
    const order = await this.#orderRepository.create({
      userId,
      items,
      total,
      paymentId: payment.id,
      status: "confirmed"
    });
    
    // Update inventory
    for (const item of items) {
      await this.#inventoryService.reserve(item.productId, item.quantity);
    }
    
    // Send notification
    await this.#notificationService.sendOrderConfirmation(userId, order);
    
    return order;
  }
}

// User of this service doesn't need to know about:
// - Inventory management
// - Payment processing
// - Database operations
// - Notification systems
```

## 🎯 Good Abstraction Principles

### 1. Single Level of Abstraction

```javascript
// Bad - mixed levels
function processOrder(order) {
  // High level
  validateOrder(order);
  
  // Low level - doesn't belong here
  const connection = mysql.createConnection({...});
  connection.query("INSERT INTO orders...");
  
  // High level
  sendConfirmation(order);
}

// Good - consistent level
function processOrder(order) {
  validateOrder(order);
  saveOrder(order);
  sendConfirmation(order);
}
```

### 2. Hide What Changes

```javascript
// Abstract the parts that might change
class PaymentGateway {
  charge(amount, paymentMethod) {
    // Implementation can change (Stripe, PayPal, etc.)
    // without affecting code that uses this class
  }
}
```

### 3. Expose What's Stable

```javascript
// Public interface should be stable
class ShoppingCart {
  addItem(product, quantity) { }
  removeItem(productId) { }
  getTotal() { }
  checkout() { }
  // These methods won't change even if implementation does
}
```

## 🎯 Summary

- **Abstraction** hides complexity, shows simple interface
- **Abstract classes** define templates for subclasses
- Use **Facade pattern** to simplify complex subsystems
- **Repository pattern** abstracts data access
- Keep **consistent levels** of abstraction
- **Hide what changes**, expose what's stable
- Good abstraction makes code easier to use and maintain
