## 📖 What is Encapsulation?

Encapsulation is bundling data (properties) and methods that operate on that data together, while restricting direct access to some components.

### The Problem Without Encapsulation

```javascript
// Without encapsulation - anyone can break the object
const bankAccount = {
  balance: 1000
};

// Anyone can do this!
bankAccount.balance = -5000;  // Invalid state!
bankAccount.balance = "hello"; // Wrong type!
```

### With Encapsulation

```javascript
class BankAccount {
  #balance = 0;  // Private - can't access from outside
  
  constructor(initialBalance) {
    if (initialBalance >= 0) {
      this.#balance = initialBalance;
    }
  }
  
  deposit(amount) {
    if (amount > 0) {
      this.#balance += amount;
      return true;
    }
    return false;
  }
  
  withdraw(amount) {
    if (amount > 0 && amount <= this.#balance) {
      this.#balance -= amount;
      return true;
    }
    return false;
  }
  
  getBalance() {
    return this.#balance;
  }
}

const account = new BankAccount(1000);
account.deposit(500);
console.log(account.getBalance());  // 1500
console.log(account.#balance);      // SyntaxError: Private field
```

## 🔒 Private Fields and Methods

### Private Fields (Properties)

Use `#` prefix to make fields private:

```javascript
class User {
  // Private fields
  #password;
  #loginAttempts = 0;
  #maxAttempts = 3;
  
  // Public field
  username;
  
  constructor(username, password) {
    this.username = username;
    this.#password = this.#hashPassword(password);
  }
  
  // Private method
  #hashPassword(password) {
    // Simple hash simulation
    return `hashed_${password}_${Date.now()}`;
  }
  
  // Private method
  #resetAttempts() {
    this.#loginAttempts = 0;
  }
  
  // Public method
  login(password) {
    if (this.#loginAttempts >= this.#maxAttempts) {
      return { success: false, message: "Account locked" };
    }
    
    if (this.#verifyPassword(password)) {
      this.#resetAttempts();
      return { success: true, message: "Login successful" };
    }
    
    this.#loginAttempts++;
    return { 
      success: false, 
      message: `Invalid password. ${this.#maxAttempts - this.#loginAttempts} attempts remaining`
    };
  }
  
  #verifyPassword(password) {
    return this.#password.includes(password);
  }
}

const user = new User("john", "secret123");
console.log(user.username);     // "john" - public
console.log(user.#password);    // SyntaxError - private!
console.log(user.login("wrong")); // { success: false, message: "..." }
```

### Convention: Underscore Prefix

Before private fields existed, developers used `_` as a convention:

```javascript
class OldStyleClass {
  constructor() {
    this._privateData = "secret";  // Convention only - still accessible!
  }
  
  _privateMethod() {
    // Convention says "don't call this from outside"
  }
}

const obj = new OldStyleClass();
console.log(obj._privateData);  // "secret" - still works!
```

**Note:** `_` is just a naming convention. Use `#` for true privacy.

## 🎛️ Getters and Setters

Control how properties are accessed and modified.

### Basic Getters and Setters

```javascript
class Temperature {
  #celsius;
  
  constructor(celsius) {
    this.#celsius = celsius;
  }
  
  // Getter - accessed like a property
  get celsius() {
    return this.#celsius;
  }
  
  // Setter - assigned like a property
  set celsius(value) {
    if (value < -273.15) {
      throw new Error("Temperature below absolute zero!");
    }
    this.#celsius = value;
  }
  
  // Computed property (getter only)
  get fahrenheit() {
    return (this.#celsius * 9/5) + 32;
  }
  
  set fahrenheit(value) {
    this.celsius = (value - 32) * 5/9;  // Uses celsius setter for validation
  }
  
  get kelvin() {
    return this.#celsius + 273.15;
  }
  
  set kelvin(value) {
    this.celsius = value - 273.15;
  }
}

const temp = new Temperature(25);
console.log(temp.celsius);     // 25
console.log(temp.fahrenheit);  // 77
console.log(temp.kelvin);      // 298.15

temp.fahrenheit = 100;
console.log(temp.celsius);     // 37.78

// temp.celsius = -300;  // Error: Temperature below absolute zero!
```

### Validation with Setters

```javascript
class User {
  #email;
  #age;
  
  get email() {
    return this.#email;
  }
  
  set email(value) {
    const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
    if (!emailRegex.test(value)) {
      throw new Error("Invalid email format");
    }
    this.#email = value.toLowerCase();
  }
  
  get age() {
    return this.#age;
  }
  
  set age(value) {
    if (typeof value !== "number" || value < 0 || value > 150) {
      throw new Error("Invalid age");
    }
    this.#age = Math.floor(value);
  }
}

const user = new User();
user.email = "JOHN@Example.COM";
console.log(user.email);  // "john@example.com"

// user.email = "invalid";  // Error: Invalid email format
// user.age = -5;           // Error: Invalid age
```

### Read-Only Properties

```javascript
class Circle {
  #radius;
  
  constructor(radius) {
    this.#radius = radius;
  }
  
  get radius() {
    return this.#radius;
  }
  
  // No setter = read-only from outside
  
  get area() {
    return Math.PI * this.#radius ** 2;
  }
  
  get circumference() {
    return 2 * Math.PI * this.#radius;
  }
  
  // Method to change radius with validation
  scale(factor) {
    if (factor > 0) {
      this.#radius *= factor;
    }
  }
}

const circle = new Circle(5);
console.log(circle.radius);  // 5
console.log(circle.area);    // 78.54...

// circle.radius = 10;  // Doesn't work - no setter
circle.scale(2);
console.log(circle.radius);  // 10
```

## 🏗️ Encapsulation Patterns

### Builder Pattern with Encapsulation

```javascript
class UserBuilder {
  #user = {};
  
  setName(name) {
    this.#user.name = name;
    return this;  // Enable chaining
  }
  
  setEmail(email) {
    this.#user.email = email;
    return this;
  }
  
  setAge(age) {
    this.#user.age = age;
    return this;
  }
  
  setRole(role) {
    this.#user.role = role;
    return this;
  }
  
  build() {
    // Validate before building
    if (!this.#user.name || !this.#user.email) {
      throw new Error("Name and email are required");
    }
    
    // Return a copy, not the internal object
    return { ...this.#user, createdAt: new Date() };
  }
}

const user = new UserBuilder()
  .setName("John")
  .setEmail("john@example.com")
  .setAge(25)
  .setRole("admin")
  .build();
```

### Immutable Objects

```javascript
class ImmutablePoint {
  #x;
  #y;
  
  constructor(x, y) {
    this.#x = x;
    this.#y = y;
    Object.freeze(this);  // Prevent adding new properties
  }
  
  get x() { return this.#x; }
  get y() { return this.#y; }
  
  // Return new instance instead of modifying
  move(dx, dy) {
    return new ImmutablePoint(this.#x + dx, this.#y + dy);
  }
  
  scale(factor) {
    return new ImmutablePoint(this.#x * factor, this.#y * factor);
  }
  
  toString() {
    return `Point(${this.#x}, ${this.#y})`;
  }
}

const p1 = new ImmutablePoint(3, 4);
const p2 = p1.move(1, 2);

console.log(p1.toString());  // "Point(3, 4)" - unchanged
console.log(p2.toString());  // "Point(4, 6)" - new point
```

## 🎯 Benefits of Encapsulation

### 1. Data Integrity

```javascript
class Inventory {
  #items = new Map();
  
  addItem(name, quantity) {
    if (quantity <= 0) return false;
    
    const current = this.#items.get(name) || 0;
    this.#items.set(name, current + quantity);
    return true;
  }
  
  removeItem(name, quantity) {
    const current = this.#items.get(name) || 0;
    if (quantity <= 0 || quantity > current) return false;
    
    this.#items.set(name, current - quantity);
    return true;
  }
  
  getQuantity(name) {
    return this.#items.get(name) || 0;
  }
  
  // Return copy, not reference
  getAllItems() {
    return Object.fromEntries(this.#items);
  }
}
```

### 2. Implementation Hiding

```javascript
class PasswordManager {
  #passwords = new Map();
  #encryptionKey;
  
  constructor(masterPassword) {
    this.#encryptionKey = this.#deriveKey(masterPassword);
  }
  
  // Users don't need to know HOW encryption works
  #deriveKey(password) {
    // Complex key derivation hidden
    return `key_${password.split('').reverse().join('')}`;
  }
  
  #encrypt(data) {
    // Encryption implementation hidden
    return btoa(data + this.#encryptionKey);
  }
  
  #decrypt(data) {
    // Decryption implementation hidden
    const decoded = atob(data);
    return decoded.replace(this.#encryptionKey, '');
  }
  
  // Simple public interface
  store(site, password) {
    this.#passwords.set(site, this.#encrypt(password));
  }
  
  retrieve(site) {
    const encrypted = this.#passwords.get(site);
    return encrypted ? this.#decrypt(encrypted) : null;
  }
}
```

### 3. Easier Refactoring

```javascript
// Internal implementation can change without affecting users
class ShoppingCart {
  // Could change from array to Map without breaking external code
  #items = [];
  
  addItem(product, quantity = 1) {
    const existing = this.#items.find(i => i.product.id === product.id);
    if (existing) {
      existing.quantity += quantity;
    } else {
      this.#items.push({ product, quantity });
    }
  }
  
  getTotal() {
    return this.#items.reduce(
      (sum, item) => sum + item.product.price * item.quantity, 
      0
    );
  }
  
  getItemCount() {
    return this.#items.reduce((sum, item) => sum + item.quantity, 0);
  }
}
```

## 🎯 Summary

- **Encapsulation** bundles data and methods, restricts access
- Use **#** prefix for truly private fields and methods
- **Getters/Setters** control property access with validation
- **Read-only** properties have getters but no setters
- Benefits: data integrity, implementation hiding, easier refactoring
- Return **copies** of internal data, not references
