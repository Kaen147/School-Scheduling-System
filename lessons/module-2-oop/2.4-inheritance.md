## 📖 What is Inheritance?

Inheritance allows a class to inherit properties and methods from another class. It represents an "is-a" relationship.

```
Animal (parent/base/superclass)
   ↓
  Dog (child/derived/subclass)

"A Dog IS AN Animal"
```

### Basic Inheritance

```javascript
// Parent class (superclass)
class Animal {
  constructor(name) {
    this.name = name;
  }
  
  speak() {
    console.log(`${this.name} makes a sound`);
  }
  
  eat() {
    console.log(`${this.name} is eating`);
  }
}

// Child class (subclass)
class Dog extends Animal {
  constructor(name, breed) {
    super(name);  // Call parent constructor
    this.breed = breed;
  }
  
  // Override parent method
  speak() {
    console.log(`${this.name} barks!`);
  }
  
  // Add new method
  fetch() {
    console.log(`${this.name} fetches the ball`);
  }
}

const dog = new Dog("Buddy", "Golden Retriever");
dog.speak();  // "Buddy barks!" (overridden)
dog.eat();    // "Buddy is eating" (inherited)
dog.fetch();  // "Buddy fetches the ball" (new)
console.log(dog.name);   // "Buddy" (inherited property)
console.log(dog.breed);  // "Golden Retriever" (own property)
```

## 🔑 The super Keyword

### super() in Constructor

Must call `super()` before using `this` in child constructor:

```javascript
class Vehicle {
  constructor(brand, year) {
    this.brand = brand;
    this.year = year;
  }
}

class Car extends Vehicle {
  constructor(brand, year, model) {
    // MUST call super() first!
    super(brand, year);  // Calls Vehicle constructor
    this.model = model;  // Now we can use 'this'
  }
}

// This would error:
class BadCar extends Vehicle {
  constructor(brand, year, model) {
    this.model = model;  // Error! Must call super() first
    super(brand, year);
  }
}
```

### super.method() to Call Parent Methods

```javascript
class Animal {
  speak() {
    return `${this.name} makes a sound`;
  }
}

class Dog extends Animal {
  speak() {
    // Call parent method and extend it
    const parentMessage = super.speak();
    return `${parentMessage}... specifically, ${this.name} barks!`;
  }
}

const dog = new Dog();
dog.name = "Buddy";
console.log(dog.speak());
// "Buddy makes a sound... specifically, Buddy barks!"
```

### Practical Example

```javascript
class User {
  constructor(name, email) {
    this.name = name;
    this.email = email;
    this.createdAt = new Date();
  }
  
  getInfo() {
    return `${this.name} (${this.email})`;
  }
  
  canAccess(resource) {
    return resource.isPublic;
  }
}

class AdminUser extends User {
  constructor(name, email, department) {
    super(name, email);
    this.department = department;
    this.role = "admin";
  }
  
  getInfo() {
    return `${super.getInfo()} - Admin (${this.department})`;
  }
  
  // Override - admins can access everything
  canAccess(resource) {
    return true;
  }
  
  // Admin-only method
  deleteUser(user) {
    console.log(`Admin ${this.name} deleted user ${user.name}`);
  }
}

const user = new User("John", "john@example.com");
const admin = new AdminUser("Jane", "jane@example.com", "IT");

console.log(user.getInfo());   // "John (john@example.com)"
console.log(admin.getInfo());  // "Jane (jane@example.com) - Admin (IT)"
```

## 🔄 Method Overriding

Child classes can override parent methods to provide specialized behavior:

```javascript
class Shape {
  constructor(color) {
    this.color = color;
  }
  
  area() {
    return 0;  // Default implementation
  }
  
  describe() {
    return `A ${this.color} shape with area ${this.area().toFixed(2)}`;
  }
}

class Rectangle extends Shape {
  constructor(color, width, height) {
    super(color);
    this.width = width;
    this.height = height;
  }
  
  area() {
    return this.width * this.height;
  }
}

class Circle extends Shape {
  constructor(color, radius) {
    super(color);
    this.radius = radius;
  }
  
  area() {
    return Math.PI * this.radius ** 2;
  }
}

class Triangle extends Shape {
  constructor(color, base, height) {
    super(color);
    this.base = base;
    this.height = height;
  }
  
  area() {
    return (this.base * this.height) / 2;
  }
}

const shapes = [
  new Rectangle("red", 4, 5),
  new Circle("blue", 3),
  new Triangle("green", 6, 4)
];

shapes.forEach(shape => {
  console.log(shape.describe());
});
// "A red shape with area 20.00"
// "A blue shape with area 28.27"
// "A green shape with area 12.00"
```

## 📚 Inheritance Chain

Classes can extend other classes that extend other classes:

```javascript
class LivingThing {
  constructor(name) {
    this.name = name;
    this.alive = true;
  }
  
  die() {
    this.alive = false;
  }
}

class Animal extends LivingThing {
  constructor(name, species) {
    super(name);
    this.species = species;
  }
  
  move() {
    console.log(`${this.name} moves`);
  }
}

class Mammal extends Animal {
  constructor(name, species) {
    super(name, species);
    this.warmBlooded = true;
  }
  
  nurse() {
    console.log(`${this.name} nurses its young`);
  }
}

class Dog extends Mammal {
  constructor(name, breed) {
    super(name, "Canis familiaris");
    this.breed = breed;
  }
  
  bark() {
    console.log(`${this.name} barks!`);
  }
}

const buddy = new Dog("Buddy", "Golden Retriever");

// Has access to all inherited methods
buddy.bark();   // From Dog
buddy.nurse();  // From Mammal
buddy.move();   // From Animal
buddy.die();    // From LivingThing

// instanceof checks the entire chain
console.log(buddy instanceof Dog);         // true
console.log(buddy instanceof Mammal);      // true
console.log(buddy instanceof Animal);      // true
console.log(buddy instanceof LivingThing); // true
```

## 🛡️ Protected Members (Convention)

JavaScript doesn't have true protected members, but we use conventions:

```javascript
class Component {
  constructor(id) {
    this.id = id;
    this._state = {};  // "Protected" - for subclasses
  }
  
  // "Protected" method - subclasses should override
  _render() {
    throw new Error("Subclass must implement _render()");
  }
  
  // Public method
  mount(container) {
    container.innerHTML = this._render();
  }
  
  // "Protected" - subclasses can use
  _setState(newState) {
    this._state = { ...this._state, ...newState };
    this._onStateChange();
  }
  
  _onStateChange() {
    // Override in subclass
  }
}

class Button extends Component {
  constructor(id, label) {
    super(id);
    this._state = { label, clicked: false };
  }
  
  _render() {
    return `<button id="${this.id}">${this._state.label}</button>`;
  }
  
  click() {
    this._setState({ clicked: true });
  }
  
  _onStateChange() {
    console.log("Button state changed:", this._state);
  }
}
```

## ⚖️ Inheritance vs Composition

### When to Use Inheritance

Use inheritance for "is-a" relationships:

```javascript
// Good: A Car IS A Vehicle
class Vehicle { }
class Car extends Vehicle { }

// Good: A Manager IS AN Employee
class Employee { }
class Manager extends Employee { }
```

### When to Use Composition

Use composition for "has-a" relationships:

```javascript
// Bad: A Car IS AN Engine? No!
class Engine { }
class Car extends Engine { }  // Wrong!

// Good: A Car HAS AN Engine
class Engine {
  start() { console.log("Engine started"); }
  stop() { console.log("Engine stopped"); }
}

class Car {
  constructor() {
    this.engine = new Engine();  // Composition
  }
  
  start() {
    this.engine.start();
    console.log("Car is ready to drive");
  }
}
```

### Composition Example

```javascript
// Instead of complex inheritance...
class FlyingAnimal extends Animal { }
class SwimmingAnimal extends Animal { }
class FlyingSwimmingAnimal extends ??? { }  // Problem!

// Use composition
const canFly = {
  fly() {
    console.log(`${this.name} is flying`);
  }
};

const canSwim = {
  swim() {
    console.log(`${this.name} is swimming`);
  }
};

const canWalk = {
  walk() {
    console.log(`${this.name} is walking`);
  }
};

class Animal {
  constructor(name) {
    this.name = name;
  }
}

class Duck extends Animal {
  constructor(name) {
    super(name);
    // Mix in abilities
    Object.assign(this, canFly, canSwim, canWalk);
  }
}

class Fish extends Animal {
  constructor(name) {
    super(name);
    Object.assign(this, canSwim);
  }
}

const duck = new Duck("Donald");
duck.fly();   // "Donald is flying"
duck.swim();  // "Donald is swimming"
duck.walk();  // "Donald is walking"
```

## 🎯 Static Inheritance

Static members are also inherited:

```javascript
class Animal {
  static kingdom = "Animalia";
  
  static describe() {
    return `Animals belong to kingdom ${this.kingdom}`;
  }
}

class Dog extends Animal {
  static species = "Canis familiaris";
  
  static describe() {
    return `${super.describe()}. Dogs are ${this.species}`;
  }
}

console.log(Animal.kingdom);    // "Animalia"
console.log(Dog.kingdom);       // "Animalia" (inherited)
console.log(Dog.species);       // "Canis familiaris"
console.log(Dog.describe());    // "Animals belong to kingdom Animalia. Dogs are Canis familiaris"
```

## 🎯 Summary

- **Inheritance** creates "is-a" relationships between classes
- Use **extends** to create a subclass
- Call **super()** in constructor before using `this`
- Use **super.method()** to call parent methods
- **Override** methods to provide specialized behavior
- Prefer **composition** over inheritance for "has-a" relationships
- Keep inheritance hierarchies shallow (2-3 levels max)
