# Scheduling System

## Installation Guide

Follow these steps to install and run the system on your device.

### Prerequisites

- Node.js (v14 or higher)
- npm

### Backend Setup

1. Navigate to the backend directory:
```bash
cd backend
```

2. Install dependencies:
```bash
npm install
```

3. Start the backend server:
```bash
npm run dev
```

### Frontend Setup

1. Navigate to the frontend directory:
```bash
cd frontend/scheduling
```

2. Install dependencies:
```bash
npm install
```

3. Start the frontend development server:
```bash
npm run dev
```

### Running the Application

Once both servers are running:
- Backend will typically run on `http://localhost:5000`
- Frontend will typically run on `http://localhost:5173`

Open your browser and navigate to the frontend URL to access the application.
